# WiSync — Website

Site da **WiSync** — *Inovação que organiza o seu negócio*. Consultoria empresarial, criação de sistemas e formação profissional (Office, Power BI e Inteligência Artificial).

## Como editar
| O quê | Onde |
|---|---|
| WhatsApp, telefones, email, morada, redes sociais | `js/config.js` |
| Cores da marca | topo de `css/style.css` (variáveis `--blue`, `--sky`, `--navy-*`) |
| Textos, serviços e formações | `index.html` |
| Logótipo (vetorial, animado no topo) | `assets/wisync-icon.svg` |

No GitHub: abra o ficheiro → lápis (Edit) → altere → **Commit changes**. O site actualiza em 1–2 minutos.

## Depois de editar CSS ou JS
Aumente a versão (`?v=1.0` → `?v=1.1`) nos links do `index.html` para os visitantes receberem logo a versão nova.

## Publicação
GitHub Pages, ramo `main`, pasta raiz.
